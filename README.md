# Nishita Ranka Brand Landing Page

Standalone brand landing page for Dr. Nishita Ranka's skin, hair and aesthetic
clinic in Banjara Hills, Hyderabad.

## What This Repo Contains

- One landing page at `/`
- Brand page content for skin, hair, laser, chemical peel, medi facial and
  aesthetic care concerns
- A three-field consultation form that opens a prefilled WhatsApp enquiry
- Responsive desktop/mobile layouts with a mobile sticky consultation sheet
- Focused render tests for the brand page and form systems

## Development

```sh
npm install
npm run dev
```

## Verification

```sh
npm run lint
npm test
```

## Notes

This repo intentionally does not include the old treatment-specific routes,
database examples, generated build folders, dependency folders or an existing
Sites project binding.
